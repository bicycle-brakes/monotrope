**The runner-side mechanism already exists — `save_attempt` in `scripts/stage2.py`.** The function `save_attempt(root, baseline, change, label)` (scripts/stage2.py:4187) snapshots the whole worktree after a failed model call through a temporary index seeded with the baseline, commits the tree with the runner's own identity (`SAVE_IDENTITY`, `stage2 runner <stage2@localhost>`, scripts/stage2.py:4179) and stores it under a local ref `refs/stage2/attempts/{change}/{label}-{stamp}`, the stamp in UTC `%Y%m%dT%H%M%S%fZ` form. The commit's parent is the baseline, so `git diff <baseline> <ref>` shows everything the run left (docstring, scripts/stage2.py:4188–4199). A failing save is named and never blocks the restore that follows (`except (Refused, OSError)`, scripts/stage2.py:4213–4214). It is called at exactly three sites, all in the failed-call recovery paths of the work verbs: implement/repair at scripts/stage2.py:7121 and 7195 with label `f"{verb}-attempt-{attempt}"`, draft at scripts/stage2.py:7778 with label `f"draft-attempt-{attempt}"`. No other caller exists in the tree (search for `save_attempt(` found only the definition and those three sites). The failure message names the ref and the diff command; a real example is quoted in `plans/changes/restore-symlink-parent/findings.md` ("the attempt is saved at refs/stage2/attempts/demo/implement-attempt-1-20261023T173338920538Z (f4e9b535b1ca); `git diff …` shows it"), and the format is pinned by `tests/test_stage2.py:19654`. The answer text itself travels separately: `save_answer_evidence` (scripts/stage2.py:4266) writes the protected answer into the worktree's own git directory under `stage2/attempts/<change>/attempt-{n}-{token}.md` — a file, not a ref — "local evidence like `refs/stage2/attempts/`, tracked by no path and carried by no branch push" (docstring, scripts/stage2.py:4271–4273).
