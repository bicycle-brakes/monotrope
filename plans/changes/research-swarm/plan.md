## Build sequence

1. Establish the public transport/tool contract without sending repository
   content: use the pinned runtime's model inventory to map the three free
   ids to its actual provider/address; do not assume `opencode-go/<free-id>`.
   Record unread terms/residency as unknown. Implement the scoped declaration
   check for `public-web`; the default framework check still refuses unknown
   residency and public-only endpoints. Public search needs page retrieval,
   no new paid API, and real source receipts; unsupported transport/tools
   refuse or fail visibly rather than substituting a model or fake sources.
2. Build the public extension and isolated Pi launcher first. Disable every
   built-in local tool and discovery surface, allow only this extension, use
   fresh scratch cwd/home/config and an allow-listed environment, and capture
   only public search/fetch receipts. Copy the public prompt and audited
   extension into generic scratch paths before loading them. Pin DNS-validated
   connections and check
   every redirect; reject local/authenticated/private destinations. Run an
   offline capture with real pinned Pi and synthetic private canaries against
   a local mock model server before enabling any external free call. Capture
   model prompts, tool schemas and tool requests; attempt file/shell tools,
   repository discovery and private-URL fetches. Do not call this measured
   merely because a stand-in's argv is correct.
3. Add class dispatch: read all available `--class`/spec/research declarations,
   reject absent/invalid/conflicting input with Stage 2 on, and preserve the
   explicit Haiku fallback. Freeze the private packet and its state digest;
   include bounded runner-collected git history, architecture and adjacent
   specs because Pi's file tools alone are no git-history command.
4. Before the free stage, run one fresh headless Opus 5.5 call (effort
   `high`, 5-minute deadline, own leak check and audit) on the private brief
   to write the public topic (spec criterion 23, Q-6). Accept it only through
   the mechanical filter: one sentence, at most 20 words, no path, file name,
   identifier-shaped token, change name or bead id; otherwise stop with exit 1
   before any free call. Record the accepted sentence in the research.
   Run every declared free researcher next on fixed generic briefs plus that
   one topic sentence. Initial
   focuses are LongCat on topics 1/4, Space Bunny on 2/3 and HY4 on 5/6.
   Then run separate DeepSeek/MiMo Flash contexts for each of topics 1–5,
   and DeepSeek Flash for topic 6 paired with HY4's public contribution.
   Share only public reports and the same private input packet with Flash
   peers, never a peer's answer. Buffer private report text until all peers
   finish, writing only audit identities/outcomes during their stage; flush
   all collected reports on stage completion or failure. No private-to-public
   packet conversion exists.
5. Use one fresh headless official Claude Code call on `claude-opus-5-5`,
   `xhigh`, with read-only tools and no foreign endpoint environment. Supply
   all six pairs, public receipts/excerpts, original source pointers and
   failed-slot markers. Validate its six distinct topic ids and citations;
   distinguish facts, applicability, dissent, gaps and human questions.
   Append its reconciliation and compact original reports to `research.md`.
6. Before each call, validate the role's declaration, leak-check its exact
   prompt with the current tree/history, and write its own audit. Scrub
   credentials from all outputs/receipts/diagnostics. Use monotonic deadlines:
   10 minutes per researcher, 5 for the topic call, 15 for the judge, 150 for the whole run; each launch
   takes the smaller remaining allowance. One invocation per roster member,
   one topic call, eleven Flash calls and one judge (sixteen initially), no retries, recursive
   delegation or debate. Preserve non-security failures, attempt remaining
   scheduled roles within the budget, and exit 1 for any incomplete run;
   declaration/leak refusals record the blocked slot, exit 2 and stop, never
   claiming a clean audit for that slot. Changed frozen inputs also fail
   publication. Audit/appended research does not invalidate its own digest.
7. Move the doctrine and endpoint remarks together, retaining other routing
   behavior and the review ladder. Update model-group resolvers to check the
   declared swarm roster, not simply exempt an unresolvable label. Keep new
   endpoint tests fixture-based so the kit's empty declaration can carry them
   without raising its exception cap. Run the checks below and the reviews;
   present the decision pull request with approval pending. After its merge,
   qualify actual public-only model/search/page retrieval through the runner
   and record outcomes before claiming a complete live swarm. A failed live
   qualification leaves the swarm unavailable, with explicit Stage-1 escape.
