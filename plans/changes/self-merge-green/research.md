**The doctrine that bounds any self-merge.** ADR 0008 (`docs/adr/0008-merge-confirms-a-decision.md`, Decision, provenance `human-decided`): a decision takes effect when the maintainer merges its pull request or asks an agent in the conversation; contract bullet "An agent merges only on request, with the decision in view" (restatement in conversation and as PR comment, stop on red CI, never `--admin`, `--match-head-commit`); bullet "Claude Code asks before every merge command it recognises", the ask rules coming from one list (`scripts/merge_guard.py`). Its Consequences name the upgrade path if an agent is ever found deciding on the maintainer's behalf: agents under a bot identity of their own and branch protection requiring an approval by someone other than the pusher — option (c), "not now". `prompts/07-commit.md`, section "The merge", opens "**You do not sign off your own work.** The merge belongs to the maintainer: they merge, or explicitly ask an agent to, after the agent has restated the decision block. This holds for every pull request" — steps 1–8, where step 7 reads which freshness alternative holds from the API (`gh api repos/{owner}/{repo}/rules/branches/main --jq '[.[].type]'` lists `merge_queue`), admits to the queue at the exact head with no branch update first, reports "queued" versus "merged" (only `gh pr view <n> --json state,mergeCommit` showing `MERGED` counts), and step 8 keeps the `gh pr update-branch` recovery for the no-queue alternative. `docs/WORKFLOW.md` §2 ("A decision takes effect…" and the "What this does not do" list) repeats the doctrine and names the ask rules' pass-arounds: `curl`, the web page, `gh` behind `sh -c '…'` or an absolute path, a moved flag (`gh pr --squash 54 merge`), a GraphQL mutation read from a file, an alias set by `gh alias import`. Rule RB-M2 (`docs/governance/regelwerk.md`, table "M — Human Gates"): under one GitHub account the person's approval *is* their merge — by themselves or by an agent on their explicit request after restating — "a rule, not proof, and it ends once agents work under their own identity".
